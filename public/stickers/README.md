# 房间表情包

当前没有表情包素材，`catalog.json` 保持空数组，游戏中显示“暂无表情包”。

后续将有授权的素材文件放在本目录，并向 `catalog.json` 添加条目即可：

```json
[
  { "id": "hello", "label": "打招呼", "src": "/stickers/hello.webp" }
]
```

只使用本地 SVG、PNG、JPEG、GIF 或 WebP，扩展名小写；路径和文件名使用英文、数字、连字符、下划线。不要填写外部网址、数据网址或 `..` 路径。ID 保持稳定，`label` 用于按钮和图片的无障碍文字，不超过 30 个 Unicode 码点；最多配置 60 项。

客户端点击条目后立即发送独立的表情包消息，不插入文字输入框。服务器按清单校验 ID。素材与清单随正常版本发布，并重启服务器后生效。
