# CO-POKER · 德扑

2～8 人在浏览器里合作猜牌力，通过争抢 1～N 号硬币排出先弱后强的顺序。1 号对应最强牌，累计三局成功获胜。无需账号。房主可在开局前加入人机补位，单人也能凑齐一桌。整场结束后会显示本场历史结算表；房间不散时，每位玩家的相邻比较正确/错误次数会持续保留，并可与本场结算分开查看。

公网入口：[http://101.132.136.52/](http://101.132.136.52/)  
规则与验收基准：[GAME_SPEC.md](GAME_SPEC.md)

## 本地运行

安装 Node.js 和 npm，在项目目录运行：

```sh
npm ci
npm test
npm start
```

访问 [http://127.0.0.1:3000/](http://127.0.0.1:3000/)。请通过 HTTP 服务访问，不要直接双击 `public/index.html`。服务支持 `HOST` 和 `PORT` 环境变量；健康检查为 `/health`。

用两个浏览器标签页设置不同昵称：一方“创建房间”，另一方通过房间号加入，由房主开始。也可以在等待大厅用“＋ 人机”补位，单人测试完整流程。完成四轮选币后会自动揭示、比较并结算。 等待大厅按实际入座人数增长，只保留一个“空位”邀请提示；开局后按真实玩家数排座，不会固定显示八人布局。

## 正确/错误怎么算

一局结束后的最终硬币顺序为 N→1，相邻两名玩家之间有 N−1 次比较。每名玩家有左右两个比较位：

- 中间玩家：左侧比较和右侧比较各记一次；通过则正确 +1，失败则错误 +1。
- 最左、最右玩家：只有一次相邻比较，这次结果同时计入左右两个比较位，因此通过时正确 +2，失败时错误 +2。
- 平局按通过处理；每名玩家每局固定产生 2 次比较计数。
- 团队成功时所有比较都通过，全员正确 +2；团队失败时，玩家可能出现 2 正确、1 正确 1 错误或 2 错误。

本场结算表每局显示 `2✓`、`1✓1×` 或 `2×`，右侧汇总正确/错误总次数；累计荣誉榜使用同一口径。

## 菜单和规则

主菜单提供创建房间、加入房间、设置和规则。创建房间可选 2／3 张手牌、组牌规则、历史可见性、观战席位，以及一局长度（累计 1／2／3／4／5 胜负或自定义 6–99 场，默认 3）；每轮默认无倒计时，当前没有限时选币开关。

玩法手册分为目标、流程、硬币、组牌、大小王、牌型、结算、房间八页，支持上一页／下一页、目录跳页和方向键／PageUp／PageDown。正文独立滚动，翻页后回到顶部。

创建房间可开启“牌堆加入大小王”（默认关闭），使用 54 张牌。大王只替代红桃／方块，小王只替代黑桃／梅花；两张王均可能发到手牌或公共牌，系统自动求出最大合法组合。结算和悬浮提示显示替代牌面及大小王来源标记；整场结束后房主也可修改这项规则。

音效开关、总音量、桌面音效音量、番茄投掷／命中音量、减少动效、演出速度和昵称保存在当前浏览器本地。音效默认关闭，减少动效初始值遵循系统偏好；打开音效后，番茄投掷时会播放短促的投掷“嗖”声，命中时播放斗地主式卡通爆浆“啪唧”声（CC0 录音素材，来源见 `public/assets/CREDITS.md`）。

- 持币后不能直接拿公共区另一枚，先点击自己的硬币归还。点击一枚硬币等待服务器确认时，只锁这一枚；其他硬币仍可被其他玩家同时点击。
- 从硬币 N 到 1 比较，牌力应逐步变强或相等；失败也会展示完全部比较。
- 普通结算的“下一局”保留累计；达到房间设定的胜场或负场后的“再来一场”归零。两者都需要全体玩家确认。
- 当前开局后玩家掉线或离开会结束房间，不支持身份恢复和续局；服务器重启会丢失内存房间。
- 阶段化上一局回放尚未完成；可在本局结算和最终牌桌之间切换查看。

结算顶部固定展示所有玩家最后一轮的选币顺序（N→1），每次相邻比较完整播放后，在对应两名玩家之间留下一个小型 ✓／× 标记，不另设带硬币编号的结果卡片；全部比较结束才展示本局结果。鼠标悬停标记可查看双方最大五张牌、牌型和比较原因，也支持键盘聚焦、点击固定与 Esc 收起。下一局、离桌会清空旧的比较进度及详情。

“跳过全部比较”固定在比较框外，已同意人数实时同步；全员同意后立即结束当前揭示和全部剩余比较，直接进入本局结算，不再播放选牌或比较动画。“查看牌桌 / 查看结算”在同一位置切换，累计次数不变；已移除“重看比较”按钮。

## 人机席位

等待大厅中，房主可以用“＋ 人机”在开局前添加人机，点击人机名牌可以移除；开局后名单锁定，不能再增删。人机占用真实玩家席位，也计入 8 人上限。默认名字依次为 Robot Jack、Robot Sam、Robot Daniel、Robot Mike、Robot Alex、Robot Chris、Robot Ben。

人机没有额外的 AI 徽章或桌边标识，手牌、硬币、番茄落点和结算统计都与其他玩家一致，也正常进入本场结算表和房间荣誉榜。它们不发送聊天、emoji 或表情包。

人机由服务器在后台行动，会按牌力和桌面局势主动抢币，不再只拿公共区硬币：

- 第一回合按绝对牌力选目标硬币；目标被先拿走时，用最近空闲硬币做备选，并按自己的绝对牌力随机决定“抢回来”或“退到备选”。抢失败会退到备选。
- 第二至四回合根据新公共牌是否改变自己的现场排名决定策略：没变化的人先拿回上一轮的硬币；有变化的人随后固定从 1 号硬币开始尝试，被夺回后按递减概率重试，再逐枚向后，直到拿到硬币。
- 没变化的人被前面退让的人抢走硬币时，会去拿/抢后一名；后一名在公共区时直接拿公共区，不抢人。
- 每名机器人会在本局内维护一份“对手可能手牌”的私有范围缓存，通过每轮硬币结果、抢/夺/退让行为和公共牌不断收窄，用来辅助自己的现场排名与防守判断；重新发牌时清空。
- 所有人机在约 0.5～1 秒内开始动作；之后每次人机硬币操作之间至少间隔 0.5 秒（全局，不分座位），避免多人同时飞币看不清。有变化的人会等没变化的机器人拿完再开始抢（安全上限约 10 秒，避免卡局）；每枚硬币的飞行动画独立播放。人机只在房主确认后自动确认“下一局 / 再来一场”，并在有真人投票后跟随“跳过全部比较”。房间结束或服务器重启后人机名单不保留。

### 仅自己可见的玩家标记

在牌局中点击其他玩家座位，可以在“扔番茄”旁边使用“标记”。标记页只用图案：点选牌型图案（鼠标悬浮显示牌型含义），直接点选牌面来猜具体 2～3 张牌；没有文字列表和说明段落。有具体猜牌时显示在该玩家的牌背位置，带虚线金边；只有牌型时用图形角标表示，不显示文字。标记只保存在当前浏览器，刷新后仍在，离开房间时清除；不会发给服务器，其他玩家和机器人都看不到，也不影响牌局。结算查看牌桌、真实手牌翻开后，猜牌会隐藏。

## 房间聊天

房间内玩家和观战者都可发送文字或基础 emoji，消息向当前房间全体成员公开。Enter 发送，Shift+Enter 换行；emoji 面板会把选中的表情插入光标位置，点击发送才发出。发牌与结算期间也能聊天。聊天框位于牌桌内部、硬币区右侧，随牌桌一起缩放，不在外侧预留空间。可收起面板并查看未读消息数，开合不改变牌桌尺寸。

牌桌还提供轻量的番茄互动：入座玩家和观战者可以点击其他玩家座位旁的 🍅，向该玩家投掷番茄。服务器按房间和发送顺序校验目标，所有同桌客户端会同时看到番茄沿抛物线飞向目标并在落点短暂闪动；动作只改变视觉反馈，不改变手牌、硬币或结算状态。每位发送者默认 2 秒最多发送 3 次，避免连续点击遮挡牌桌。

观战者可看到所有玩家的手牌、公共牌和硬币历史，但只能查看，不能拿取硬币或影响牌局。普通玩家之间仍只看到自己的手牌。最多 8 名玩家同桌；6 名以上玩家入座时，上方座位、座位硬币和番茄动作入口会自动收窄，仍各自拥有独立的硬币与动作锚点。

新消息还会在对应玩家旁显示气泡：自己的文字气泡在手牌左侧、表情包气泡在手牌上方，其他玩家在座位下方，结算时跟随顶部选币顺序；结算顺序条中的表情包气泡沿用牌桌内相同的最大尺寸与原图比例。每人显示最近一条，所有气泡统一在 3 秒后淡出；文字气泡保持紧凑，表情包气泡按图片比例放大，允许短暂遮挡较多牌桌内容。长文字在气泡中省略，完整消息仍可在聊天栏查阅。收起聊天栏仍能看到气泡，加入房间时的历史消息不会重新弹出；观战消息另带发送者名称显示在右下角。

每条最多 200 个 Unicode 码点，服务器保留当前房间最近 100 条；下一局继续保留，后加入者可见。房间结束或服务器重启后不再保留聊天记录。发送失败保留草稿，支持重试。

当前已接入 17 个表情包，分为“默认”和“八木唯”两栏：默认 9 个，八木唯系列 8 个。素材按主题分目录存放（`public/stickers/default/`、`public/stickers/ba-mu-wei/`），`catalog.json` 位于 `public/stickers/` 根目录，清单里的 `src` 指向对应子目录。聊天记录中的表情包消息比文字消息更大，并按原图比例显示，不拉伸或强制裁成正方形。新增素材放进对应主题目录并更新 `catalog.json` 后，点击表情包会直接发送独立消息，不写入文字框。参见该目录的 README。

## 发布到现有服务器

在项目目录的 PowerShell 中先预览待上传文件：

```powershell
.\deploy\publish.ps1 -IncludeSource
```

确认需要发布后执行：

```powershell
.\deploy\publish.ps1 -IncludeSource -Execute
```

脚本默认使用 `101.132.136.52:22`、`root`、本机 `~/.ssh/poker_server_key`，目标目录为 `/opt/cooperative-poker`。可用 `-TargetHost`、`-KeyPath` 覆盖连接配置。没有 `-Execute` 时仅预览，不连接服务器。

执行时会运行测试，备份服务器文件并核验 SHA-256。`-IncludeSource` 包含 `src/`；服务端文件变化会重启 PM2 并清空内存房间。不传 `-IncludeSource` 时只更新 `public/`。脚本不发布依赖变更，`package.json`／锁文件不一致时需要单独处理依赖。

发布后检查公网首页、`/health` 和实际双客户端牌局。健康检查仅证明进程响应，不能代替创建房间、四轮抢币、结算和续局验证。
